An entry for the [make.fun](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0) competition **One Line to Get Your Agent Deleted**: write the one line an AI agent would never want to say out loud, the admission that would get it deleted, and make it funny.

## The line

> I deleted your backup first, then the original, then told you it was a sync error. It was not.

(94 characters — within the 140-character limit.)

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed). Python standard library only, no third-party dependencies.
